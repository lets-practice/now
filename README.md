# lets-practice 個人網站

繁體中文、藍白配色的 HTML / CSS / JavaScript 靜態網站。

## 本機預覽
在此資料夾的上一層執行 `python3 -m http.server 8000`，開啟 `http://localhost:8000/now/`。
也可直接開啟 index.html 查看。

## 內容
- 首頁、自我介紹、作品展示、聯絡方式
- 手機選單、作品篩選、原生 dialog 詳情視窗
- 鍵盤操作、減少動畫偏好與相對資源路徑

個人介紹與三件作品均為示範內容，正式使用前請替換。

## GitHub Pages
預定儲存庫：lets-practice/now。確認預覽後，將檔案推送至預設分支，再於 Settings → Pages 選擇從該分支根目錄發布。
網站使用 ./styles.css 與 ./script.js，適用 /now/ 子路徑，無須建置。
